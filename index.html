01About

I'm an Infrastructure & Security Engineer based in Casablanca, working across multiple production environments in regulated financial services.

Linux and open source are home base: Kubernetes and Docker for orchestration, Proxmox and KVM for virtualization, Ansible and Terraform for automation, Prometheus and Grafana for observability, WireGuard and OpenVPN for secure access. Windows Server, Active Directory, Azure and Google Cloud are just as much a part of the job — most environments end up being a mix, and the tool follows the problem, not the other way around. I run this where an outage has real financial and regulatory consequences, which shapes how I build things — boring, observable, and reversible, in that order.

On each engagement, I own the full infrastructure stack — network, security, virtualization, databases, monitoring and incident response — rather than a narrow slice of it.

02Experience

Infrastructure & Security Engineer 2023 — Present

Long-running infrastructure engagements for financial services clients, where downtime carries real regulatory and financial weight. Each one covers the same ground — network, security, virtualization, databases, monitoring and incident response — built and run as a single continuous responsibility rather than handed off in pieces.

Leasing & Finance

A leasing and corporate-loan platform built on Kubernetes and PostgreSQL, paired with a Django/Redis/Celery pipeline for reporting. Built the monitoring and security layer from the ground up — Prometheus, Grafana and Checkmk for full-stack visibility, Wazuh and Sophos for threat detection — and designed a zero-trust access model spanning OpenVPN, NetBird, Twingate and Cloudflare. Production, UAT and test all run under the same operational discipline, including the infrastructure regulatory reporting depends on.

Banking

Across multiple banking clients: led core-banking migrations of live T24 environments off Windows cloud servers onto on-premise Linux — server builds, OS reconfiguration, security hardening and SQL Server migrations, through UAT to go-live. Upgraded aging Windows Server and SQL Server estates and reconfigured T24 around them with systems staying live in production throughout, no downtime window to hide behind.

Handle JBoss administration and the creation and configuration of new T24 environments end to end — the technical layer: environment, middleware, infrastructure. Not the functional or business side. Continue supporting the system and network layer across these engagements.

Microfinance

Administer critical cloud and application infrastructure for multiple microfinance banking platforms — a Java stack on Docker Swarm, backed by MariaDB and a BI/reporting layer. Full ownership of monitoring, security and production support, including the Oracle OCI cloud infrastructure these platforms run on.

Infrastructure & security practice

Beyond individual engagements: network architecture, firewall design and security policy, Proxmox and VMware virtualization, database administration across SQL Server and Oracle, ownership of the monitoring stack, vulnerability management with OpenVAS and Nessus, and security awareness training built and delivered internally — plus occasional development work, including an internal security-awareness training tool.
